### 👨‍💻 About Me

I am a **Mechanical Engineering Student** at **G.L. Bajaj Institute of Technology and Management**, passionate about building scalable systems through **DevOps, Cloud Computing, Automation, and Infrastructure Engineering**.

* 🔭 **Current Focus:** Building hands-on DevOps projects involving **AWS, Docker, Terraform, CI/CD pipelines, Kubernetes, and Infrastructure Automation**.

* 💼 **Experience:** Building real-world projects focused on cloud infrastructure, automation, self-healing systems, and actively exploring **Open Source contributions**.

* 🌱 **Learning & Certifications:** Currently learning **Kubernetes, Advanced AWS, Platform Engineering, and Infrastructure as Code (IaC)** while strengthening Linux and cloud fundamentals.

* ⚡ **Fun Fact:** I enjoy automating repetitive work and treating infrastructure as code rather than manual configuration.
